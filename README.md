# VOXM v2.0 — Voice Memory Transformer（Web / PWA版）

声をリアルタイムに変換し、声を「メモリチップ」として保存・装着して使うアプリ。
2026-11-19 に ChatGPT 版の引き継ぎ（VOXM PRECISION UI v1）から **作り直し** た版です。

## すぐ試す

| 方法 | マイク変換 | 備考 |
|---|---|---|
| Claude アプリ内のプレビュー | ✕（ブラウザの安全制限） | 見た目・操作・ファイル変換を確認できる |
| `dist/` をHTTPSで公開して iPhone Safari で開く | ◯ | **本番の使い方**。ホーム画面に追加でアプリのように起動 |
| PC の Chrome / Edge で開く | ◯ | 出力先を仮想ケーブルにすれば Discord / Zoom / OBS / LINE PC版で使える |

公開のしかた:
- **GitHub Pages（自動）**: main に push すると `.github/workflows/pages.yml` が `https://zoukapu-design.github.io/voxm/` に公開
- **TestFlight（自動）**: Actions →「iOS TestFlight」→ Run workflow。設定は **[docs/SETUP_TESTFLIGHT.md](docs/SETUP_TESTFLIGHT.md)**
- ローカル: `python3 tools/build.py` → `dist/` をHTTPSで配信

※ マイクは HTTPS（または localhost）でしか動きません。`file://` で開いても変換は動きません。

## 動くもの（実装済み・テスト済み）

- **メモリホイール**: 写真付きチップを左右スワイプ（慣性・スナップ）、タップで回転
- **ドライバーへの挿入**: 中央チップを**下にドラッグ**（またはタップ）→ スロットに差し込まれ、カチッという音・本体の揺れ・LED点灯。挿入中チップはスロットから頭が出て見え、タップで取り出し。別チップをタップすると差し替え
- **リアルタイム変換**（端末内の信号処理・サーバー不要）
  - ピッチと声色（フォルマント）を**別々に**変えられる TD-PSOLA 方式。AudioWorklet で動作（古い端末は ScriptProcessor に自動切替）
  - ロボット（抑揚固定）、電子のゆらぎ（リング変調）、ダブラー、エコー、リバーブ、ドライブ、ラジオ/電話
  - 音量を自動で揃える処理つき。処理遅延は約35ms（＋端末の遅延）
- **友達の声メモリ**: 本人同意チェック → 自分の基準声 → 友達の声（10〜30秒）を録音 or ファイル → 声の高さと声色の差を自動測定してプロファイル化 → 自分の録音で試聴
- **ケース**（似た声をまとめる）: ケース作成・色・チップの出し入れ、ドライバーに並べるケースの切替、**「似た声で自動まとめ」**（メカ系 / 響く系 / ローファイ / 高い声 / 低い声 / 自然な声）
- **FX工房**: 3スロットのラック、強さ調整、全体ピッチ微調整、出力音量、「この声をチップに保存」
- **出力ハブ**: モニター / 録音して共有（iPhoneの共有シート→LINE等） / 変換ボイス付き自撮り動画 / 音声ファイル変換（WAV） / PC出力先の選択（仮想ケーブル） / 診断（エンジン種別・遅延）
- 端末内保存（IndexedDB）: チップ・写真・録音・ケース・設定。クラウド送信なし
- 音量ノブ（本体右側を上下ドラッグ）、操作音、動きを減らす設定

## まだできないこと（正直な状況）

| 項目 | 状況 |
|---|---|
| 友達本人そっくりの**AI声質変換**（RVC等） | 未実装。今は「高さと声色の傾向」を近づける簡易プロファイル |
| iPhoneの**LINE通話アプリ**にリアルタイムで流す | iOSの仕様で不可（他アプリのマイクを置き換えられない） |
| VOXM同士の通話 | 未実装（WebRTC＋シグナリングサーバー、または LINE Planet SDK が候補） |
| iPhone単体からのライブ配信 | 未実装（PC＋OBSなら可） |
| iPhone Safari 実機での遅延・操作感の確認 | **未確認**（Chromium の自動テストのみ実施） |

## テスト

- `node tests/dsp.test.js` — 合成音声で、ピッチ×1.5/×0.75、声色×1.18、ロボ固定、音量、測定精度を数値検証（全項目パス）
- `python3 qa/qa.py` / `qa/qa_flow2.py` — Chrome（偽マイク・偽カメラ）で 320〜768px のレイアウト重なり、スワイプ→挿入→変換ON→録音→差し替え→FX→ケース自動まとめ→作成→友達プロファイル→ファイル変換→動画→再読み込み後の保存 を確認。JSエラー0
- `qa/shots/` に各画面のスクリーンショット

## ファイル構成

```
dist/            公開用（index.html 1ファイル＋PWA用 manifest / sw.js / icon）
src/dsp-core.js  変換エンジン本体（PSOLA・ロボ・リング変調）— Worklet/フォールバック/テスト共通
src/analysis.js  声の測定（F0・声色エンベロープ・ワープ推定）
src/engine.js    Web Audio の接続、FXチェーン、録音、出力先、効果音
src/store.js     IndexedDB 保存
src/app/*.js     画面（10 基盤/アイコン/アート, 20 データ, 30 共通UI, 40 変換, 50 メモリ/ケース, 60 作成, 70 FX, 80 出力, 90 起動）
src/styles.css   デザイン
tools/build.py   src → dist の1ファイル化
capacitor.config.json  iOSアプリ化（Capacitor 8）
ci/              iOSプロジェクトの調整スクリプトと書き出し設定
.github/workflows/  TestFlight ビルド / GitHub Pages 公開
```
